# IMDB Movie Review Sentiment Analysis

## Project Overview
This project classifies IMDB movie reviews as **positive** or **negative** using deep learning and Natural Language Processing (NLP).

The notebook compares CNN, LSTM, and Bidirectional LSTM architectures. The Streamlit application uses the saved Bidirectional LSTM model to predict sentiment for a user-entered review.

## Files
- `app.py` — Streamlit prediction interface
- `IMDB_dataset_(NLP).ipynb` — notebook containing preprocessing, exploratory analysis, model training, evaluation, and model saving
- `bilstm_sentiment_model.h5` — trained BiLSTM model (generated by running the notebook's Model Saving section)
- `tokenizer.pkl` — fitted text tokenizer (generated by the notebook)
- `requirements.txt` — Python dependencies
- `model_config.json` — saved model configuration and evaluation details (optional)

## Dataset
The project uses the IMDB movie reviews dataset. The notebook loads the file `IMDB Dataset.csv` and currently reads up to 5,000 rows for the experiment.

Dataset source: https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews

## Run Locally
1. Install Python.
2. Open a terminal in this project folder.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Ensure `bilstm_sentiment_model.h5` and `tokenizer.pkl` are in the same folder as `app.py`.
5. Start the app:

   ```bash
   streamlit run app.py
   ```

6. Open the local URL shown in the terminal (usually http://localhost:8501).

## Notes
- The app requires the trained model and tokenizer files; it does not train the model when launched.
- The model's preprocessing and sequence length are aligned with the notebook.
- Do not upload secrets, credentials, or private data.
